== Description ==

**Store One** is an all-in-one WooCommerce sales booster that replaces a stack of single-purpose plugins. Add **BOGO and Buy X Get Y offers**, **shoppable videos**, **product search**, **side cart**, **sales popup notifications**, a **sticky add to cart bar**, a **Buy Now button**, **trust badges**, **sale countdown timers** and **visitor count** from one lightweight plugin and one dashboard.

Turn each module on only when you need it, so your store stays fast and your plugin list stays short.

== Installation ==

1. Upload the `store-one.zip` to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Get started from Dashboard > Store One

If you're facing any problem while using our Store One plugin, Please first follow the below steps :
1. Deactivate all plugins you are using and check if the problem is still occurring with our Store One Plugin.
2. Check the theme and plugin version, if it is latest or not.
3. Check the plugin with default theme, to make sure error is not due to theme you're using.
You're free to contact us through mail, via our Contact form and Live chat support. We have also given full documentation of our Plugin, you can go with it and learn how to use our plugin.
